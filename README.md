Research Navigator

Research Navigator is a lightweight, Streamlit‑powered web application designed to help researchers, students, and AI enthusiasts quickly discover and preview the latest papers on arXiv.

Features

Topic Search: Enter any keyword or phrase (e.g., agentic AI, graph neural networks) and retrieve the top N relevant arXiv papers.

Recency Filter: Use an intuitive slider to include only papers published within the last X days.

Clean Listing: View each paper’s title, authors, publication date, categories, and a short abstract in a professional two‑column layout.

PDF Download: One‑click links to open or download the full PDF on arXiv.
